# IT-2321 Lab 6: Forms, Fetch, and Live Data

**Week 12 | Reading: Eloquent JavaScript, Chapters 10, 11, and 18**

This lab is practice with validating a form, fetching live JSON with the Fetch API, and displaying the result on the page.

## Getting started

1. Rename this repository to `it2321-lab06-lastname` (your last name, all lowercase) and set it to Private.
2. Clone it and open the folder in Visual Studio Code.
3. Open `index.html` in your browser, and open the developer console to see your output.
4. Write your code in `script.js`, replacing each `TODO` with your own work.

## What to do

- Handle the form's submit event and prevent the default reload.
- Validate the input and show a clear message when it is missing.
- Fetch live JSON from a web service with the Fetch API.
- Handle both a successful response and a failed one.
- Display something from the returned data on the page through the DOM.

## Files

- `index.html` — the page that loads your script. You usually do not need to change much here.
- `script.js` — where your work goes.
- `styles.css` — basic styling you may adjust.
